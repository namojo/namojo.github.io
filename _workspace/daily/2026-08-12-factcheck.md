## C. 초고 대비 수정 사항 (검증 결과 반영 완료)

1. [치명적 → 수정] 초고는 망 보강 비용 부담 방식을 "자기 월 전기요금 인상분으로 내겠다"고 **기제까지 단정**했으나, 이는 2차 요약(opentools·blockchain.news)에만 등장하고 NBC·Tom's Hardware 등에서 1차 확인 불가 → **기제 서술 삭제**, 확인된 사실(설비 보강 비용 100% 부담 + 소비자 인상분 보전)만 남김.
2. [치명적 → 수정] 초고는 이 약속의 시점을 밝히지 않아 Theseus 발표(8/10)와 동시로 오독될 수 있었음 → **"지난 2월"** 명기. Theseus 보도자료는 기존 약속의 재확인임을 문장으로 분리.
3. [보강] 검증 중 확보한 아모데이 직접 인용을 블록 인용으로 추가(팩트 카드에 없던 항목이나 1차성 인용으로 확인됨).
4. [경미 → 수정] "지난 8월 10일" → "지난 10일" (같은 달이므로 중복 표기 제거).
5. [경미 → 수정] 21번 항목의 단일 출처 수치(메타·구글 금액)는 사용하지 않고 정성 서술로 대체.
6. [품질 검수] "목적 건축(purpose-built)됩니다" → "전용으로 지어집니다"(불필요 병기 제거, 어색한 조어 해소), "눈에 걸리는 것" → "정작 주목할 대목"(구어체 순화), "과반을 이들이" → "과반도 이들이"(조사 호응), "계량기 안쪽/바깥쪽"에 작은따옴표 1회 적용(저자가 코인한 대조 구문에 한정).
