## GTIG·Mandiant 보고서 핵심 (2026-11-02, 직접 인용)
- "LLM Mixers function as illicit routing gateways that proxy, aggregate, and resell unauthorized LLM access to underground subscribers."
- "The threat actors used open-source API gateways and custom relay infrastructure to **pool stolen credentials, meter usage, and obscure the origin of the requests**."
- UNC6993이 new-api·gcli2api 사용 — "likely to aggregate stolen keys and balance request loads across accounts"
- LiteLLM `/key/regenerate` 엔드포인트의 user ID rebind 취약점 **CVE-2026-40217**로 일반 Virtual Key를 PROXY_ADMIN 마스터 자격증명으로 승격
- Jet Night(`jet-night.com`): "more than 500,000 LLM API calls in less than eight hours", 피해 조직에 "nearly one million dollars in token costs" 전가. **월 약 60달러 무제한 플랜** — 통상 "$100 and $250 per month"보다 낮아 GTIG는 "the service relies on stolen keys to operate profitably"로 판단
- 개별 사고에서 하루 $100,000 초과, 일부 조직 누적 $1,000,000까지
- 지배적 초기 침투 경로: "exposed or stolen cloud identity tokens — including IAM credentials, Service Account keys, GitHub Personal Access Tokens (PATs), and active session tokens"
- 권고: 중앙 시크릿 관리·자동 순환 / 최소 권한(클라우드 LLM 서비스 접근도 명시적으로 필요할 때만) / **키 스코프를 모델 엔드포인트·환경(dev/prod)·사용량 한도로 제한** / **검증 스윕 모니터링 — "anomalous, low-volume requests (such as `max_tokens=1` or zero-temperature pings)"** / 게이트웨이 패치(CVE-2026-40217) / 예산 경보·지출 상한 / 피싱 저항 MFA

## 바꾸는 것 (관문 1)
LLM API 키의 **위협 모델이 바뀐다.** 지금까지 키 유출의 손해는 "남이 내 모델을 쓴다" 정도로 상상됐지만, 실제로는 **현금화 경로가 완성된 상품**이다. 그래서:
- 과금 급증을 보고 알아채는 방식이 통하지 않는다 — 믹서의 설계 목적이 여러 계정에 부하를 분산해 급증을 안 만드는 것이다(GTIG: "balance request loads across accounts").
- 내일 회의에서 쓸 문장: **"우리 LLM 키는 모델 엔드포인트와 환경별로 쪼개져 있습니까? 지출 상한은 걸려 있습니까? 그리고 `max_tokens=1` 같은 저용량 호출이 갑자기 늘어난 적 있는지 로그를 볼 수 있습니까?"**
- 자체 LiteLLM 같은 게이트웨이를 운영 중이면 CVE-2026-40217 패치 여부 확인.
- SaaS 벤더가 AI 기능을 외부 추론 사업자로 돌리고 있는지(노션→파이어웍스) 서브프로세서 목록 확인.

## 설명할 메커니즘 (관문 2)
**훔친 LLM 키는 쓰는 물건이 아니라 되파는 물건이다 — 그 되팔기를 성립시키는 세 단계.**
1. **풀링(pooling):** 믹서는 여러 피해자의 키를 한 묶음으로 모은다. 구독자의 요청을 키들에 흩뿌리면 어느 한 계정도 눈에 띄게 튀지 않는다. 훔친 신용카드와 결정적으로 다른 점 — 카드는 한 장이 한 번 긁히고 끝나지만 토큰은 잘게 나뉘어 희석된다.
2. **미터링(metering):** 토큰은 이미 계량 단위다. 세탁이 필요 없다. 그래서 훔친 그 순간부터 바로 구독 상품이 된다(Jet Night 월 60달러 무제한).
3. **가격이 곧 증거:** 정상 서비스가 월 100~250달러인데 60달러 무제한이면 원가가 0이라는 뜻이다. GTIG가 "훔친 키에 의존해야만 수익이 난다"고 판단한 근거가 바로 가격표다.
→ 그리고 되팔기 전에 **키가 살아 있는지 찔러 봐야 한다.** 그게 `max_tokens=1`·temperature 0 짜리 저용량 요청이고, 침해의 유일한 선행 신호다. 비용이 거의 안 나와서 과금 경보에 안 걸린다.

**비유:** 전기 도둑. 한 집에서 몰아 쓰면 계량기가 튀니까, 여러 집 배선을 조금씩 따서 모은 뒤 한곳으로 보낸다. 각 집 고지서는 "조금 더 나왔네" 수준이라 아무도 신고하지 않는다.

## 출처 바깥의 사고 (가정 + 근거)
제로 데이터 보존(ZDR)이 추론 경로의 표준이 되는 동안, **공격면은 줄어든 게 아니라 옆으로 이동했을 가능성**이 있다. 근거 둘: (a) 파이어웍스의 두 차례 침투가 모두 ZDR 바깥 — 10/9 불리틴의 '평가 작업 시크릿', 10/23~24의 'R&D 머신' — 에서 났다. (b) 노션에서 샌 것도 추론 트래픽이 아니라 **Insights라는 분석 기능이 보관하던 대화 기록**이었다. 평가·관측·과금·R&D는 같은 데이터를 다루면서 ZDR 약속의 적용을 받지 않는다. 예측이 아니라 가정이고, 사건 두 건이 근거의 전부다.
