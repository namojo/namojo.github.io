### 압축(compaction)의 실제 동작 ★ 주논지 2 — 결정적
개발자 문서 「Compaction」 기준:
- 전체 컨텍스트 윈도를 보내면 **새로 압축된 컨텍스트 윈도를 돌려준다.**
- 돌려받은 윈도에는 **암호화된 압축 아이템(encrypted compaction item)** 이 들어 있고, 이전 상태·추론을 더 적은 토큰으로 이어 나른다.
- **그 압축 아이템은 불투명(opaque)하며 "사람이 해석할 것을 의도하지 않았다(not intended to be human-interpretable)".**
- 두 가지 방식: (1) 독립 압축 — 직접 `/responses/compact` 호출 / (2) 서버 측 압축 — `context_management`의 `compact_threshold` 설정 시 렌더된 토큰 수가 문턱을 넘으면 서버가 알아서 실행, 별도 호출 불필요
- **과금:** 자동 압축이 일어나면 **그 `responses.compact` 요청의 사용량이 같은 실행(run) 합계에 더해진다.** 사용량 항목에 `requests`(LLM API 호출 횟수), `input_tokens`, `output_tokens`, `total_tokens` 포함
- → **즉 하네스에는 요금이 없지만, 하네스가 자율적으로 하는 일은 청구되는 추론 호출이다.**

### 실행 환경 / 데이터 ★ 주논지 3 (한국 접점)
- 샌드박스 선택지: 오픈AI 호스팅 **또는** 자체 호스팅/지원 제공자 — **Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, Vercel**
- E2B는 자기 격리 샌드박스를 백엔드로 시연(머신 일시정지·포크, 애플리케이션 키를 워커에서 분리)
- ⚠ **퍼블릭 베타 동안 데이터 레지던시는 미국 한정, ZDR(zero data retention) 미지원.**
- ⚠ **자체 호스팅 샌드박스를 골라도 Agents API가 ZDR 대상이 되지 않는다** (개발자 문서 「Self-hosted sandboxes」 명시)
- **대조축:** 일반 API 플랫폼은 이미 **한국**을 포함한 다수 리전에 저장(at rest) 레지던시를 제공하고, ZDR도 적격 조직·엔드포인트 대상으로 제공한다 (2025년 확대: 유럽·영국·미국·캐나다·일본·**한국**·싱가포르·인도·호주·UAE)
- → 규제 산업 팀 입장에서 Agents API로 옮기는 것은 **이미 확보한 두 가지를 반납하는 일** (단, 베타 한정 제약이며 해제될 수 있음 — 균형에 반드시 명시)

### 스택 내 위치
- **Agents SDK**: 오픈소스, 내 애플리케이션 안에서 도는 프레임워크(내 인프라)
- **Agents API**: 오픈AI가 운영하는 **관리형 런타임**
- **Responses API** 직접 호출: 루프를 내가 소유
- Agent Builder·Evals는 **2026-11-30 이후 종료**, 코드 기반 워크플로는 Agents SDK로 유도 (⚠ 2차 출처 — 단정 피하고 '예고' 수준으로)

### 벤더 제시 성과 수치 (⚠ 반드시 귀속)
- 어떤 고객: 지연 4배 감소 / 건당 비용 60% 감소 / 실패한 에이전트 응답 86% 감소
- ⚠ 독립 검증 없음. 고객명·워크로드 미공개. 쓰려면 "오픈AI가 소개한 사례" 로만.

## 평론 각도

**주논지 — 0원이라는 숫자를 다시 읽는다 (저자 시그니처: 숫자의 맥락 재해석)**
2년 동안 에이전트를 만든 팀은 모두 같은 루프를 손으로 썼다. 세션 상태 보존, 툴 재시도, 컨텍스트가 차면 줄이기, 죽으면 살리기. 많은 팀이 이걸 자기 차별화라고 불렀다. 그것이 하루아침에 "별도 요금 없음"이 됐다.
그런데 공짜인 것은 하네스라는 **이름**이고, 하네스가 하는 **일**은 공짜가 아니다. 압축은 추론 호출이고 그 사용량은 내 실행 합계에 더해진다. 컨텍스트에 무엇을 남길지 정하는 쪽이 청구서의 크기를 정한다 — 그 결정이 이제 문턱값 하나 뒤에서 자동으로 내려진다.
게다가 그 결정의 결과물은 **암호화된 불투명 아이템**이고 문서가 "사람이 읽을 것을 의도하지 않았다"고 적어 뒀다. 에이전트의 기억이 내가 읽을 수 없는 형태로 바뀐다.

**보조 축 — 가져도 되는 한 조각이 아무것도 옮기지 않는다 (한국 접점)**
4개 프리미티브 중 자체 호스팅이 허용된 것은 환경(샌드박스) 하나다. 제공자 9곳, 자기 인프라도 가능. 그런데 그렇게 해도 ZDR 대상이 되지 않고 레지던시는 미국 한정이다. 일반 API에는 한국 리전 저장도 ZDR도 이미 있다. 금융·공공 팀이 옮기려면 이미 가진 두 칸을 반납해야 한다.

**균형 (반드시 포함)**
1. 하네스는 실제로 차별화가 아니었다 — 팀마다 같은 코드를 다시 쓴 것은 낭비였고, 그걸 없애 주는 건 진짜 이득이다.
2. Tool search는 컨텍스트를 줄이므로 비용을 **내리는** 방향이다. 압축도 원래 목적이 비용 절감이다. 한쪽으로만 읽으면 틀린다.
3. 데이터 제약은 **퍼블릭 베타 한정**이라고 오픈AI가 명시했다 — 해제될 수 있다.
4. 루프를 소유하고 싶으면 Agents SDK·Responses API 경로가 그대로 남아 있다. 강제된 이전이 아니다.
5. 성과 수치는 전부 벤더 제시.

**마무리:** 유형 6 열린 권유형 — 무엇을 위탁하고 무엇을 남길지.
