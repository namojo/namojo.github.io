## [2026-09-15] 구글이 사내 엔지니어 전원에게 경쟁사 모델 Claude Opus 5를 열었다 — 단, 도구가 아니라 모델만, 그것도 쿼터로

**발생 시점:** 현지 2026-09-15 보도 (Business Insider 단독, Hugh Langley 기자). 한국 보도 2026-09-15 오전 (ZDNet Korea 10:11, 서울경제 11:48 KST). 사내 정책 변경의 *실제 적용 시점*은 보도에 없음.
**업계 영향도:** 상
**분류:** AI 업계 / 빅테크 전략 / 개발자 도구

### 핵심 팩트

- **사건:** 구글이 그동안 대부분의 직원에게 금지해 온 경쟁사 코딩 AI 사용 정책을 뒤집고, **전 엔지니어**에게 앤트로픽의 최상위 모델 **Claude Opus 5** 사용을 허용했다.
- **경로가 핵심:** 앤트로픽의 도구인 **Claude Code는 여전히 직접 사용 불가**. 엔지니어는 구글 자체 개발 플랫폼 **Antigravity** 안에서 드롭다운으로 Opus 5를 *모델로* 선택하는 방식만 허용된다. 즉 **열린 것은 모델이고, 하네스(작업 환경·오케스트레이션)는 구글 것 그대로다.**
- **쿼터:** 직원 1인당 사용량 한도가 적용된다. **한도의 단위(토큰/요청/시간)와 크기는 미공개.**
- **종전 정책:** Claude Code·OpenAI Codex 등 외부 코딩 도구 사용 금지. Claude 접근은 **일부 구글 딥마인드 팀과 소수의 우선순위 프로젝트**로 제한돼 있었다.
- **구글 공식 코멘트 (대변인):** "Engineers can access select third-party models in Antigravity, consistent with our external Antigravity enterprise offering. **Gemini remains the primary foundation model for internal development**, and third-party models are provided on a quota basis to support specialized use cases."
  - 한국어 보도 문안(ZDNet Korea): "엔지니어는 안티그래비티를 통해 일부 서드파티 모델에 접근할 수 있다… 제미나이는 내부 개발의 주력·근간 모델로 남으며, 서드파티 모델은 특수 용도를 지원하기 위해 사용량 한도와 함께 제공된다."
- **배경(보도 기준):** 일부 구글 엔지니어가 **Gemini의 코딩 성능에 대한 불만**을 지속적으로 제기해 왔다. ZDNet Korea는 배경으로 **Gemini 3.5 Pro가 약속한 2026-06 출시를 넘겨 지연**됐고, 일부 3.5 Pro 후보 모델이 더 가벼운 Flash 계열을 능가하지 못해 폐기됐다고 전한다. (※ 이 두 항목은 국내 매체 서술 — 구글 공식 확인 아님, 본문 인용 시 출처 귀속 필요)
- **얽힘(관계도):** 구글은 앤트로픽의 최대 투자자 중 하나다. **2026-04-24 최대 400억 달러 투자 발표** — 우선 100억 달러를 **기업가치 3,500억 달러**에 투입하고, 성과 목표 달성 시 **추가 300억 달러**. 구글 클라우드는 5년간 **5GW 규모 용량**을 공급하고, 앤트로픽은 브로드컴과의 협력으로 **2027년부터 TPU 기반 다수 GW(브로드컴 증권신고서 기준 3.5GW)** 를 확보한다. 즉 **구글은 앤트로픽의 투자자·인프라 공급자·유통 채널이면서, 이제 사내 고객이기도 하다.**

### 선례: 아마존이 같은 길을 4개월 먼저 갔다

- 아마존은 자체 코딩 도구 **Kiro** 사용을 지침으로 밀고, 프로덕션 코드에 Claude Code 등 외부 도구를 쓰려면 별도 승인 절차를 거치게 했다.
- 사내 게시판 스레드에서 **약 1,500명의 직원이 Claude Code 공식 도입을 요구**하는 데 동조. "우리가 AWS Bedrock으로 파는 도구를 정작 우리는 못 쓴다"는 지적이 나왔다.
- **2026-05-04경, 아마존 소프트웨어 빌더 익스피리언스 담당 부사장 짐 호그아웃(Jim Haughwout)** 이 Claude Code 전사 즉시 허용, **Codex는 5월 12일** 추가를 공지. 인용: "To help you invent more for customers, we are expanding the agentic AI tools available to you."
- **핵심 대비:** 아마존은 *도구(Claude Code)* 를 열되 **Bedrock 위에서** 돌게 했고, 구글은 *도구는 닫고 모델만* **Antigravity 안에서** 돌게 했다. 둘 다 "경쟁사 지능을 들이되 자사 경계 안에서"라는 같은 형태다.

### 교차 확인된 공개 문서 (Antigravity 외부 제품 기준)

`antigravity.google/docs/models/` 문서에 따르면 외부 공개 제품 Antigravity의 모델 목록은:
- 구글 모델: Gemini 3.1 Pro(최고 추론), Gemini 3.8/3.7/3.6 Flash
- 서드파티: **Claude Sonnet 4.6 (thinking), Claude Opus 4.6 (thinking), GPT-OSS-120b** — Free/Pro/Ultra 플랜에서 사용 가능
- **Enterprise 플랜은 Gemini 모델만 사용 가능**
- 쿼터는 "Weekly Limit Remaining"·"Five Hour Limit Remaining" 두 축으로 표시

⚠ **주의 2건 (팩트체크 필수):**
1. 공개 문서에는 **Opus 4.6**까지 적혀 있고 보도의 **Opus 5**는 없다 — 문서 갱신 지연일 가능성이 크지만, "사내는 4.6이 아닌 5"라는 차이를 단정하려면 재확인 필요.
2. 구글 대변인은 사내 정책이 "external Antigravity **enterprise** offering과 일관된다"고 했는데, 공개 문서상 **Enterprise 플랜은 Gemini 전용**이다. 문서 갱신 지연 / 사내 계약 조건 상이 / 대변인 표현의 느슨함 중 무엇인지 **공개 정보로는 판별 불가**. 본문에서 이 불일치를 단정적으로 '모순'이라고 쓰면 안 되고, 쓴다면 "공개 문서와 대변인 설명이 어긋나 보이는데, 어느 쪽이 최신인지는 공개돼 있지 않다" 수준으로 사정거리를 그어야 한다.

### 출처가 침묵한 지점 (논지의 사정거리를 긋는 데 사용)

- **쿼터의 크기와 단위.** 1인당 한도가 주당 몇 토큰인지, 몇 시간인지 전혀 공개되지 않았다. 한도가 넉넉하면 사실상 전면 개방이고, 빡빡하면 "허용했다"는 문장만 남는다. **이 숫자 하나가 기사의 의미를 정반대로 만든다.**
- **적용 시점.** 언제부터 켜졌는지, 단계적 롤아웃인지, 파일럿인지 기간 제한이 있는지 없다.
- **대상 규모.** "전 엔지니어"의 실제 인원수, 지역·조직별 예외 여부 없음.
- **데이터 취급.** 사내 코드가 Claude로 갈 때 어디서 추론되는지(Vertex AI 경유 추정이나 **확인 안 됨**), 로그 보존·학습 제외(ZDR) 조건이 어떻게 되는지 한 줄도 없다. 경쟁사 모델에 자사 소스코드를 넣는 결정에서 가장 중요한 항목이 비어 있다.
- **비용 정산.** 구글이 앤트로픽에 API 요금을 내는지, 투자·컴퓨트 계약에 상계되는지 불명. (구글이 앤트로픽의 클라우드 공급자라는 점에서 돈의 흐름이 단순하지 않다.)
- **"불만"의 규모.** 아마존은 약 1,500명이라는 숫자가 있었지만, 구글 건은 "일부 엔지니어가 불만"이라는 정성적 서술뿐. **내부 반발이 정책을 바꿨다는 인과는 보도가 주장하지 않았다.**
- **Gemini 3.5 Pro 지연·후보 폐기**는 국내 매체 서술이며 구글 공식 확인이 아니다.

### 평론 각도 제안

**각도 A (주 논지 추천): 열린 것은 모델이고, 하네스는 열리지 않았다.**
구글은 경쟁사의 '엔진'을 사내에 들였지만 '작업 환경'은 내주지 않았다. Claude Code는 여전히 금지이고, Opus 5는 Antigravity의 드롭다운 항목 하나로 들어온다. 앤트로픽이 코딩 시장에서 실제로 파는 것은 모델 가중치가 아니라 Claude Code라는 하네스인데, 구글은 그 중 값을 매기기 쉬운 쪽(모델)만 사고 값이 붙기 시작한 쪽(워크플로·에이전트 루프·컨텍스트 관리)은 자기 것으로 남겼다. 09-12 Agents API 편에서 정리한 '마구를 채운 사람이 말의 방향을 소유한다'를 가볍게 재호출할 수 있다 — 다만 반복 인용 티가 나지 않게 한 문장으로. 덧붙일 균형: 이건 구글의 계산일 뿐 아니라 **보안·컴플라이언스상 합리적 선택**이기도 하다. 사내 코드가 흐르는 경로를 자사 IDE로 묶어두면 감사 로그와 접근 통제를 유지할 수 있다.

**각도 B: '허용'이라는 단어가 쿼터를 가린다.**
헤드라인은 "구글이 클로드를 허용했다"인데, 공개된 것은 허용 사실뿐이고 **허용의 양은 공개되지 않았다.** 사내 도구 정책에서 실제로 개발자의 하루를 결정하는 것은 허용 여부가 아니라 한도다(주당 몇 시간짜리 Opus인지). 저자 시그니처인 '숫자는 틀리지 않았지만 전부는 아니었다'의 변주로 쓰되, 이번엔 **숫자가 아예 없다는 것**이 관찰 대상이다. 한국 접점: 사내에 AI 코딩 도구를 도입하는 조직이 승인 문서에 쓰는 항목도 대개 '허용/불허'이지 '1인당 한도·초과 시 동작·모델 강등 여부'가 아니다. 억지 국산 모델 나열 없이, 도입 검토표의 빈칸이라는 형태로 접점을 만든다.

**각도 C: 사내 도구 강제는 두 번 무너졌다 — 그리고 무너지는 방식이 같다.**
아마존(Kiro → 1,500명 요구 → 5월 Claude Code·Codex 허용, 단 Bedrock 위)과 구글(Gemini 전용 → 9월 Opus 5 허용, 단 Antigravity 안에서 쿼터로)이 4개월 간격으로 같은 곡선을 그렸다. 두 회사 모두 (1) 자체 모델·자체 도구 보유, (2) 앤트로픽의 대형 투자자, (3) 앤트로픽 모델의 클라우드 유통사라는 삼중 지위다. 결론을 "수직통합의 패배"로 단정하면 과하다 — 오히려 **경계는 유지한 채 내부만 연 부분 개방**이고, 두 회사 모두 자기 인프라 위로 경쟁사 지능을 흘려보내 계측·통제 가능한 상태로 만들었다. 마무리는 양가성 제시형(유형 7)이 어울린다.
