# 팩트 카드 — 2026-09-01 (KST)

## 선정 토픽
앤트로픽이 Claude Code 주간 사용량 한도 변경을 "영구 25% 인상"으로 발표했으나, 실제로는 현재 대비 17% 감소였던 사건. 같은 시기 Sonnet 5 API 가격은 9월 1일 인상 예정을 취소하고 도입가를 영구화.

## 왜 이 토픽인가
- **평론 각도가 명확하다:** 같은 회사가 3주 사이에 두 개의 숫자를 발표했는데, 하나는 누구나 검산할 수 있는 숫자(토큰당 달러)이고 하나는 아무도 검산할 수 없는 숫자(구독 한도의 배수·퍼센트)다. 전자는 지킨다는 발표였고, 후자는 인상으로 포장된 감소였다. **앤트로픽은 구독 한도의 절대 토큰 수를 공개하지 않는다** — 5x, 20x 같은 배수와 퍼센트만 공개한다. 그래서 +25%와 -17%가 같은 변화를 가리킬 수 있다.
- 저자 시그니처("숫자는 틀리지 않았지만, 전부는 아니었다")와 정확히 맞는 구조.
- 한국 엔지니어 독자 접점: Claude Code 정액 구독으로 팀 예산을 잡는 개발 조직이 용량 계획을 세울 근거가 없다는 실무 문제.
- 중복 확인: 08-01은 오픈AI GPT-5.6 API 가격 인하(다른 회사·다른 사안), 08-26은 앤트로픽 Claude Tag 분류기(다른 사안), 07-04는 토큰맥싱→효율(다른 사안). 재탕 아님.
- 오늘(9/1)이 원래 Sonnet 5 가격이 오르기로 예정돼 있던 날 → 시점 훅으로 유효.

### B. 구독 한도의 표기 방식 (논지의 핵심)
- 앤트로픽은 **어떤 플랜에도 주간·5시간 한도의 절대 토큰 수를 공개하지 않는다.** 공개하는 것은 배수뿐: Pro는 무료 플랜의 최소 5배(세션당), Max 5x는 Pro의 5배, Max 20x.
- 사용량은 토큰 예산이 아니라 **5시간 세션의 지분(share)** 으로 계량되며, 앤트로픽이 그 지분을 조정할 권리를 유보한다.
- 사용자가 볼 수 있는 것: Settings > Usage의 5시간 세션 바·주간 사용량·리셋 시각, Claude Code의 `/usage` 명령. 모두 **자기 소비의 비율**이지 상한의 절대값이 아니다.
- 주간 한도 자체의 도입: 2025-07-28 발표, 2025-08-28 적용. 5시간 롤링 창 위에 7일 리셋 주기 추가. 앤트로픽은 "현재 사용량 기준 구독자의 5% 미만에 적용"이라고 밝혔음.
- 참고 연혁: 2026-03-13~28 오프피크 프로모(5시간 한도 2배, 일정대로 종료), 2026-05-06 Claude Code 5시간 한도 영구 2배(주간 한도는 불변).

## 평론 각도 (제안)
검산할 수 있는 숫자와 검산할 수 없는 숫자. 가격표는 토큰당 달러라서 사용자가 직접 계산하고 비교할 수 있고, 그래서 앤트로픽은 그 숫자를 지켰다. 구독 한도는 절대값이 공개되지 않은 배수와 퍼센트라서 검산이 불가능하고, 그래서 같은 변화가 +25%로도 -17%로도 표기될 수 있었다. 이번에 뒤집힌 것은 회사의 정직함이 아니라 **기준점을 공개하지 않은 채 변화율만 발표하는 방식**이다. 커뮤니티가 몇 분 만에 검산한 것은 이번에 마침 두 퍼센트가 동시에 공개됐기 때문이고, 앤트로픽이 약속한 "사용량 가시성"이 바로 그 기준점의 공개다. 한국 접점: 정액 구독으로 팀 예산을 세우는 개발 조직에 용량 계획의 근거가 없다.
