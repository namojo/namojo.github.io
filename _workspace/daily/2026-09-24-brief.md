## 핵심 팩트

### 사건
- **날짜:** 2026년 9월 22일, 캐나다 토론토에서 열린 **ROSCon 2026**에서 발표
- **주체:** Intrinsic (알파벳 산하 산업용 로보틱스 소프트웨어 회사, 2021년 Alphabet X에서 스핀아웃, CEO 웬디 탄 화이트)
- **발표물:** Intrinsic Core™ — Apache 2.0 라이선스, GitHub `github.com/intrinsic-ai/intrinsic-core`
- 함께 공개: **Open Machine Tending Solution(OMTS)** — CNC 머신 텐딩 레퍼런스 설계. FANUC·Universal Robots 하드웨어, NVIDIA FoundationPose 지원

### 공개된 구성요소 (Intrinsic 공식 블로그 기준)
1. **Intrinsic Control** — 하드웨어 독립적 실시간 제어 프레임워크. 센서 기반 제어, **궤적 중간(mid-trajectory)에 동작을 동적으로 변경**. "로봇 암·그리퍼·센서를 드라이버를 다시 짜지 않고 교체 가능"
2. **Pose estimation** — NVIDIA FoundationPose 기반 6-DoF 자세 추정. 고정 지그(fixture) 의존 제거
3. **Motion planning** — 충돌 회피 경로 자동 생성 (관절 단위 수동 프로그래밍 대체)
4. **Grasp planning** — 실시간 센서 피드백으로 그리퍼가 부품 위치·방향에 적응
5. **Simulation services** — Gazebo 기반
6. **Camera calibration** — 카메라 캘리브레이션·물리적 정렬 자동화
7. **Intrinsic-ROS drivers** — 지원 로봇·그리퍼·3D 카메라용 사전 구성 ROS 드라이버
- 그 외: asset models, 네이티브 digital twin
- **로컬 하드웨어에서 구동** — "pre-configured software environment that runs seamlessly on local hardware", "open research project or a **private on-premises production line**"

### 공개되지 않은 것 (같은 블로그의 직접 서술)
> "Solutions built with Intrinsic Core automatically work with other Intrinsic offerings, including our **enterprise services which include advanced AI models, Intrinsic Flowstate, and industrial-grade cloud services. No refactoring or code rewrites needed.**"
- 즉 고급 AI 모델 / Flowstate(엔터프라이즈 플랫폼) / 산업용 클라우드 서비스는 유료 영역으로 남음
- Intrinsic 스스로 "prototype to production" 경로로 설명 — 오픈 코어가 유료 계층으로의 진입로

## 평론 각도 제안
**경계선이 어디에 그어졌는가.** LLM 세계에서 오픈/클로즈드의 경계는 가중치(weights)에 그어졌다. 이번에 Intrinsic이 그은 선은 다른 자리다 — **물리를 상대하는 결정론적 계층(실시간 제어·모션 플래닝·캘리브레이션·드라이버)이 나가고, 모델과 클라우드가 남았다.** 통념은 밀리초 단위 실시간 제어가 해자이고 AI는 흔해진다는 쪽인데, 이 릴리스는 반대로 읽힌다.

**사정거리 긋기(필수):** Intrinsic이 "제어는 범용재"라고 말한 적은 없다. 단정하지 말 것. 더 정확한 표현은 — 이 계층에서는 독점으로 얻는 값보다 진입로를 넓혀 얻는 값이 크다고 판단했다는 쪽. 그리고 회사가 그 진입로를 숨기지 않고 블로그에 직접 써 두었다("no refactoring or code rewrites needed").

**균형(반박):** ros2_control, MoveIt 등 오픈소스 실시간 제어·모션 플래닝은 이미 있었다. 종류가 새로운 게 아니라, **실제 제조 현장에 배포 중인 스택 자체**를 드라이버 사전 튜닝·캘리브레이션 결합 상태로 내놨다는 점이 다르다(저키 인용이 정확히 이 지점).

**거버넌스:** 2022년의 질문("알파벳 밑에서 ROS가 안전한가")에 대해 약속이 아니라 코드로 답한 셈. 다만 이것으로 거버넌스 문제가 정리됐다고 말할 수는 없다 — ROS의 IP는 여전히 OSRF에 있고, Intrinsic은 올해 2월 구글 본체로 들어갔다.

**독자 접점:** 억지 한국 접점 금지. CNC 몇 대 놓고 돌리는 중소 가공 현장은 국적 무관한 이야기이므로 일반 서술로. 마무리는 엔지니어가 내일 확인할 항목(우리 하드웨어 드라이버 커버리지, 실시간성 요구 수준, 우리 가치가 어느 계층에 있는가)으로.

**도입 템플릿:** H(사실 리드형). 최근 3편 첫 문장 점검 결과 연도로 시작한 글 없음 → 제약 없음. 관통 비유 금지.
**마무리:** 유형 6(열린 권유형) 또는 7(양가성 제시형).
