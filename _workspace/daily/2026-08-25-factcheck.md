## 수정된 항목 (초고 → 최종)

1. **모델 수 과장 (수정)**: 초고 "모델 300만 개" → 최종 "300만 개에 가까운 모델 저장소".
   - 근거: 허깅페이스 자체 블로그(State of Open Source on Hugging Face, Spring 2026)는 2026년 1~8월 공개 모델 저장소가 243만 → **296만**으로 증가했다고 밝힘. "300만 개"는 소폭 과장이므로 "가까운"으로 완화.
2. **조직 수 출처 불일치 (삭제)**: 초고 "전 세계 50만 곳이 넘는 조직" → 최종 "전 세계 수많은 팀".
   - 근거: BetaNews는 50만 곳 이상이라고 썼으나 다른 통계 집계는 10만 곳 이상으로 제시. 자릿수가 갈리는 수치라 교차 확인 실패 → **수치를 쓰지 않고 서술로 대체**. 논지에 필요한 수치가 아니었음.
3. **코드 예시 저장소 ID (수정)**: `google/gemma-3-27b` → `google/gemma-3-27b-it`.
   - 근거: 실제 허브의 저장소 ID는 `-it`(instruction-tuned) / `-pt` 접미사를 가짐. 존재하지 않는 ID를 예시로 쓰지 않도록 교정.
4. **인용 범위 축소 (수정)**: 스위스 인용의 직접 인용 범위를 "중립 플랫폼"으로 좁힘(위 표 참조).
