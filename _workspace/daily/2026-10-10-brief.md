# 데일리 팩트 카드 — 2026-10-10 (KST)

## 선정 토픽
CrowdStrike, 한국 금융권 연쇄 해킹에 중국산 오픈소스 AI 펜테스트 에이전트 ARTEX가 쓰였다고 보고. 공격자가 노출해 둔 open directory에서 Claude Code 세션 기록·메모리 파일·ARTEX 설정 파일이 발견되며 전모가 드러남.

## 핵심 사실
- **보고서:** CrowdStrike Counter Adversary Operations, 「Unknown Threat Actor Uses AI-Driven ARTEX to Target South Korean Finance」, 현지시각 2026-10-07 공개. (The Hacker News·Reuters 보도 10-08)
- **활동 시기:** 2026년 9월 말 ~ 10월 초.
- **ARTEX:** 중국에서 개발된 오픈소스 LLM 멀티에이전트 자율 침투시험 도구. GitHub 개발자 핸들 `Autumn-27`.
- **ARTEX의 주 백엔드 모델: DeepSeek v4.1-flash.** 보조로 Z.ai의 GLM-5.3, Grok 4.6. 공격자는 LLM API 리셀러 `xcai[.]pro`를 통해 DeepSeek에 접근한 것으로 추정.
- **Claude Code의 역할:** CrowdStrike·THN 모두 Claude Code가 공격을 수행했다고는 말하지 않음. 노출된 파일 중 Claude Code **세션 기록**이 있었고, 그 세션에서 공격자는 (a) 한국 유출 데이터가 어디서 거래되는지, (b) 한국 텔레그램 데이터 판매 그룹을 찾는 법을 물음. 또 이력서 작성, 텔레그램 기반 NFT gift 마켓플레이스 취약점 조사 세션도 있었음. 공격자의 Claude Code 설정 파일에는 LLM의 테스트 행동을 지시하는 중국어 펜테스트 프롬프트가 들어 있었음.
- **발각 경위:** 공격자가 통제하던 서버의 **open directory(디렉터리 목록 노출)**. 한 IP의 노출 디렉터리에 있던 중국어 지시 파일 → 홍콩 소재 IP의 두 번째 서버로 연결 → 그곳에 Claude Code 세션 기록, Claude **메모리 파일**, ARTEX 설정 파일.
- **인프라:** 홍콩 IP가 주 인프라. `38.244.50[.]120`이 한국 공격을 수행한 것으로 의심되는 ARTEX 인스턴스 호스팅. 다수 프록시 IP.
- **귀속:** 알려진 조직에 귀속하지 않음. **중간 수준 확신(moderate confidence)**으로 중국어 사용자·금전 동기로 평가. 세션에 나온 이름 "YY", 중국 대학·광둥 지역, 26세(최초 입력은 2007년 9월생으로 모순) 등 신상 정보는 "공격자의 것일 가능성이 높다"고만 하고 **확정하지 못함**. 텔레그램 계정 @YY520CN은 10-08 혐의 부인("아무것도 하지 않았다").
- **ARTEX 개발자 대응:** 2026-10-08 프로젝트 업데이트 중단·클로즈드소스 전환 선언. "학습과 인가된 보안 테스트" 목적이었고 악용은 의도에 반한다는 입장. 중국 외교부는 "사안을 알지 못한다"(로이터).
- **한국 피해:** 신한은행(대출모집인용 조회 서비스, 약 2만 5천 명), KB국민은행(직원용 모바일 업무지원시스템, 119명), 하나은행(영업지원시스템, 89명), BNK부산은행, 예가람저축은행(약 4만 명 추정). 금융당국 경찰 입건 전 조사. 5대 시중은행장 10-19 국정감사 증인 소환 추진. FSC·FSS는 유출 데이터로 인한 피싱·대출 사기 주의 당부.
- **총계 불확실:** CrowdStrike는 영향받은 조직 수를 확인하지 못한다고 명시. 한국 당국은 7곳 이상 가능성 언급, 보도별 7~9곳·약 6만 8천 명으로 차이.

## 평론 각도
헤드라인은 "AI 에이전트가 한국 은행을 털었다"인데, 보고서를 그대로 읽으면 두 가지가 더 정확하다.
1. **공격을 돌린 모델은 Claude가 아니라 DeepSeek v4.1-flash다.** Claude Code는 공격자 본인의 작업 세션(판매처 문의·이력서·다른 표적)에 등장한다. 한 사람이 여러 도구를 조립했고, 모델이 스스로 한 일이 아니다(스타일 가이드 09-13 항목 7: 행위 주체를 사람에게 귀속).
2. **적발한 것도 AI가 아니다.** 디렉터리 목록이 켜져 있는 웹서버였다. 그리고 그 안에 있던 것이 이 사건의 진짜 교훈이다 — 에이전트는 세션 기록과 메모리 파일과 설정 파일을 **공격자 자신의 디스크에** 남긴다. 공격 작전의 가장 완전한 기록을 공격자의 도구가 대신 써 두었다.
→ 엔지니어 독자용 실행 가능한 마무리: 에이전트 작업 디렉터리에 무엇이 쌓이는지(세션 기록, 메모리 파일, 프롬프트가 든 설정), .gitignore·컨테이너 이미지·백업·디렉터리 목록 설정.
- 09-13 포스트(앤트로픽 위협 보고서)는 **제공자 쪽 신호**가 주제였다. 이번은 **클라이언트 쪽 산출물**이라 중복이 아니다.
- 사정거리 긋기: CrowdStrike 스스로 귀속은 중간 확신, 신상은 확정 불가, 조직 수 미확인이라고 밝힌 지점을 본문에 그대로 적는다. 은행별 유출 경로가 전부 같은 공격자인지도 경찰이 아직 확인하지 못함.
- 도입: 템플릿 H(사실 리드형). 최근 3편은 연도로 시작하지 않았으므로 제약 없음.
