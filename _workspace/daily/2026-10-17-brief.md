## 설명할 메커니즘
소프트웨어·모델에서 '수출'의 경계 — 가중치 파일 이전은 수출, API 제공은 수출이 아님.
이유: 가중치는 복제 비용 0이라 한 번 나가면 회수·통제 불가. API는 계정 차단으로 즉시 회수 가능하고
사용 기록이 남음. 즉 가중치 공개 = 통제권의 영구 포기, API = 통제권을 쥔 대여.
